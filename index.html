Настройки оформления

Открыть / закрыть: Ctrl + Shift + K

Фактура поверхности

Выбери поверхность кнопок. По умолчанию включена крапчатая печать.

Настройки меняют только оформление кнопок. Ровная рамка выбрана по умолчанию.

Тип рамки

Обычная рамка возвращает прежний ровный контур со скруглёнными углами. Настройки неровной рамки сохраняются при переключении.

Если включить неровную рамку, каждой кнопке будет построен отдельный контур.

Сними галочку, чтобы сравнить с прежним прямоугольным фоном. Регулируй «Различие между рамками»: при 100% каждая кнопка получает максимально индивидуальный рисунок.

Ручная настройка рамки

Меняй ползунки — все рамки обновляются сразу, а масштаб одинаков со всех сторон. Настройки сохраняются в этом браузере.

Поделиться оформлением

Ссылка содержит режим рамки (ровная или неровная), значения ползунков, рисунок и стиль поверхности.
